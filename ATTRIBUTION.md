# Атрибуция

Этот проект является неофициальным русским переводом и адаптацией
**Open Music Theory, Version 2**.

Оригинальный учебник создан Mark Gotham, Kyle Gullings, Chelsey Hamm,
Bryn Hughes, Brian Jarvis, Megan Lavengood и John Peterson совместно с авторами
отдельных глав и участниками проекта. Канонический источник и сведения об
авторах: <https://viva.pressbooks.pub/openmusictheory/>.

Оригинал распространяется по лицензии CC BY-SA 4.0, кроме материалов, для
которых указаны иные условия. Перевод и адаптация изменяют язык, структуру
представления и, при необходимости, пояснения для русскоязычной аудитории.

Перевод не одобрен и не аффилирован с авторами оригинального учебника.
Атрибуция конкретной главы должна сохранять имя её автора из оригинального
источника. Изображения, ноты, аудио, видео и интерактивные материалы разрешено
добавлять в репозиторий только после проверки их лицензии.

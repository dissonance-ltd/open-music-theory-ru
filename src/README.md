# Открытая теория музыки

Неофициальный русский перевод и адаптация **Open Music Theory, Version 2** — открытого учебника по теории музыки.

Для первого знакомства доступны три черновика:

1. [Введение в учебник](introduction.md).
2. [Введение в западную музыкальную нотацию](fundamentals/01-western-notation.md).
3. [Запись нот, ключей и добавочных линеек](fundamentals/02-notes-clefs.md).

Пилот основан на англоязычной адаптации **Nebraska, Fall 2023**. Его соответствие текущей редакции VIVA ещё не проверено. Перевод требует независимой музыкально-теоретической рецензии. Английские рабочие листы и внешнее видео пока не переведены.

Перед чтением ознакомьтесь с [правилами обозначения нот и октав](translation-notes.md). Рабочие соответствия терминов собраны в [глоссарии](glossary.md).

Исправления и предложения можно направлять через [репозиторий проекта](https://github.com/dissonance-ltd/open-music-theory-ru).

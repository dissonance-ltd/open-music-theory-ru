# Открытая теория музыки

Это неофициальный русский перевод и адаптация учебника **Open Music Theory,
Version 2**.

Сейчас мы создаём основу проекта: структуру книги, правила атрибуции, механизм
отслеживания изменений оригинала и англо-русский словарь музыкальных терминов.
Первым полноценным этапом станет раздел «Основы».

Черновые главы будут явно помечаться. Статус «опубликовано» означает, что текст
проверен как минимум на терминологическую согласованность и соответствие
английскому оригиналу.

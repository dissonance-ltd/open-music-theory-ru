# Рабочий глоссарий

Все соответствия со статусом «кандидат» требуют рецензирования. Эта страница генерируется из `glossary/terminology.yml`.

| English | Русский термин | Примечание | Статус |
|---|---|---|---|
| accidental | знак альтерации | Знак изменения высоты: диез, бемоль, бекар и двойные знаки. | кандидат |
| alto clef | альтовый ключ | Ключ до на третьей линейке снизу. | кандидат |
| audiate | внутренне слышать | Мысленно представлять звучание музыки. | кандидат |
| bass clef | басовый ключ | Ключ фа на четвёртой линейке снизу. | кандидат |
| beam | вязка | Горизонтальная или наклонная линия, соединяющая штили; не путать с лигой. | кандидат |
| brace | акколада | Здесь фигурная скобка, объединяющая два нотных стана. | кандидат |
| clef | ключ |  | кандидат |
| compound meter | метр с трёхчастным делением доли | Рабочее описательное соответствие. Английское compound относится к делению основной доли на три; не равно безусловно русскому «сложный размер». | кандидат |
| double flat | дубль-бемоль | Понижает основной звук на тон. | кандидат |
| double sharp | дубль-диез | Повышает основной звук на тон. | кандидат |
| enharmonic equivalence | энгармоническое равенство | Разное написание одного звучания в рассматриваемом строе; в этой главе — равномерная темперация. | кандидат |
| flag | флажок |  | кандидат |
| flat | бемоль | Понижает основной звук на полутон. | кандидат |
| generic interval | ступеневая величина интервала | Счёт ступеней с включением обоих крайних звуков; не число полутонов. | кандидат |
| grand staff | объединённый нотный стан | Рабочее соответствие: два нотоносца, объединённых для записи одной партии, например фортепианной. | кандидат |
| half step | полутон | На описанной клавиатуре — расстояние до ближайшей клавиши любого цвета; 1/12 равномерно темперированной октавы. | кандидат |
| interval | интервал | Соотношение двух звуков по высоте; в начальном изложении — расстояние между ними. | кандидат |
| ledger line | добавочная линейка |  | кандидат |
| meter | метр | Не смешивать с графическим обозначением размера. | кандидат |
| middle C | до первой октавы | C4 в научной нумерации октав; номер октавы в DAW может отличаться. | кандидат |
| milieu | социально-культурная среда | Контекст создания и употребления системы записи. | кандидат |
| mnemonic device | мнемонический приём | Способ облегчить запоминание, например фраза по начальным буквам. | кандидат |
| musical notation | музыкальная нотация | Система записи музыки; не только привычная пятилинейная запись. | кандидат |
| natural | бекар; неальтерированный звук | Название знака — бекар; при описании ноты — без повышения или понижения. | кандидат |
| note | нота | В этой главе — знак, обозначающий высоту и длительность звука; в других контекстах слово может обозначать сам звук. | кандидат |
| notehead | головка ноты |  | кандидат |
| octave | октава | Интервал между одноимёнными звуками с отношением частот 2:1; также название участка звукоряда. | кандидат |
| octave equivalence | октавная эквивалентность | Одноимённость звуков в разных октавах, а не равенство их высот. | кандидат |
| parallel keys | одноимённые тональности | Например, до мажор и до минор; не переводить как «параллельные». | кандидат |
| pitch | высота звука | Требуется согласовать употребление термина как свойства звука и как отдельной высоты. Варианты: звуковысотность. | кандидат |
| pitch class | высотный класс | Особенно важно согласовать с терминологией теории множеств. Варианты: класс высот. | кандидат |
| range | диапазон | Совокупность высот, доступных голосу или инструменту; также расстояние между крайними высотами. | кандидат |
| relative keys | параллельные тональности | Например, до мажор и ля минор. | кандидат |
| rhythm | ритм |  | кандидат |
| scale degree | ступень гаммы |  Варианты: ступень звукоряда. | кандидат |
| second | секунда | Интервал, не единица времени. | кандидат |
| sharp | диез | Повышает основной звук на полутон. | кандидат |
| simple meter | метр с двухчастным делением доли | Рабочее описательное соответствие; не равно безусловно русскому «простой размер». | кандидат |
| staff | нотный стан | Допустимый синоним: нотоносец. | кандидат |
| stem | штиль |  | кандидат |
| tenor clef | теноровый ключ | Ключ до на четвёртой линейке снизу. | кандидат |
| time signature | тактовый размер (обозначение) | В зависимости от контекста: размер или обозначение размера. | кандидат |
| tonicization | тоникализация | Выбор зависит от принятой терминологии функциональной гармонии. Варианты: временная тонизация. | кандидат |
| treble clef | скрипичный ключ | Ключ соль на второй линейке снизу. | кандидат |
| voice leading | голосоведение |  | кандидат |
| whole step | тон | Интервал в два полутона; не путать с другими значениями слова tone. | кандидат |

# Основы

Начните с [введения в музыкальную нотацию](01-western-notation.md), затем переходите к [записи нот, ключей и добавочных линеек](02-notes-clefs.md).

Это первые две главы пилотного перевода. Они помогут понять, что передаёт нотная запись, из каких частей состоит нота и как пользоваться нотным станом. Задания по ссылкам пока представлены на английском языке.

Далее планируются чтение ключей, клавиатура, полутоны и тоны, ритм и метр, гаммы, интервалы и аккорды. Все текущие главы имеют статус **черновика**.

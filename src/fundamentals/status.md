# Статус перевода

| Этап | Значение |
|---|---|
| Не начато | Исходная глава ещё не импортирована |
| Черновик | Есть рабочий перевод, возможны ошибки |
| Терминология проверена | Термины сверены с глоссарием |
| Содержание проверено | Перевод сопоставлен с оригиналом |
| Опубликовано | Глава готова для основного сайта |

Текущий этап раздела: **подготовка исходников**.

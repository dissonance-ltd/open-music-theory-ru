# Open Music Theory RU

Неофициальный русский перевод и адаптация учебника
[Open Music Theory, Version 2](https://viva.pressbooks.pub/openmusictheory/).

Проект находится на начальном этапе. Первая цель — перевести и рецензировать
раздел **Fundamentals**, одновременно сформировав устойчивый англо-русский
словарь терминов.

## Принципы перевода

- музыкальный смысл важнее буквального соответствия;
- спорные термины фиксируются в `glossary/terminology.yml`;
- при первом употреблении может приводиться английский термин;
- статус и версия исходника отслеживаются отдельно для каждой главы;
- черновой машинный перевод не считается опубликованным переводом без проверки.

## Локальная сборка

Установите [mdBook](https://rust-lang.github.io/mdBook/):

```bash
cargo install mdbook --version 0.4.52 --locked
mdbook serve --open
```

Статическая версия собирается командой `mdbook build` в каталог `book/`.

## GitHub Pages

В настройках репозитория откройте **Settings → Pages → Build and deployment**
и выберите **Source: GitHub Actions**. После слияния изменений в `main`
workflow `Deploy GitHub Pages` соберёт и опубликует книгу. Его также можно
запустить вручную из вкладки Actions.

## Следующий этап

- Импортировать официальный экспорт OMT2 и записать хеш исходного файла.
- Сохранить структуру глав, авторство и сведения о правах на материалы.
- Согласовать базовый глоссарий и правила обозначения нот и октав.
- Перевести введение и первые главы раздела Fundamentals.

Пока репозиторий содержит только каркас проекта: импортёр и переводы глав
ещё не реализованы.

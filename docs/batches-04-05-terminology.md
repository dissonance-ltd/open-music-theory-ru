# Общие рабочие решения для пакетов 04–05

База: `5e86308f2213f06f38757755bac35c1ff4a60dd8`, Nebraska Fall 2023. Все соответствия — рабочие `candidate`, не результат человеческой рецензии. Сохраняем B = си, B♭ = си-бемоль, C4 = до первой октавы, ma/mi и исходные буквенные обозначения. Используем глоссарий базы; новые решения добавляет координатор.

| Английский термин | Рабочее соответствие / граница понятия |
|---|---|
| simple meter | метр с двухчастным делением доли; не автоматический синоним русского «простой размер» |
| compound meter | метр с трёхчастным делением доли; не автоматический синоним русского «сложный размер» |
| duple / triple / quadruple meter | двухдольный / трёхдольный / четырёхдольный метр: число долей в такте, отдельное от деления доли свойство |
| beat | доля; в определении метрическая доля |
| beat division / subdivision | деление доли / дальнейшее деление; сохранить конкретный уровень из примера, не смешивать число долей с числом частей доли |
| meter / time signature | метр / обозначение тактового размера; различать организацию времени и её запись |
| downbeat / upbeat | по контексту первая доля такта / движение руки вверх или последняя доля; не автоматически «затакт» |
| anacrusis / pickup | затакт |
| tie / slur / beam | соединительная лига / лига легато / вязка |
| key / key signature | тональность / ключевые знаки |
| major / minor scale | мажорная / минорная гамма |
| scale degree | ступень гаммы; над цифрами ступеней сохранить исходные обозначения |
| relative / parallel keys | параллельные / одноимённые тональности, соответственно |
| natural / harmonic / melodic minor | натуральный / гармонический / мелодический минор |
| leading tone / subtonic | вводный тон / субтоника; пояснить отличие VII ступени в полутоне и тоне ниже тоники |
| movable do / fixed do | система подвижного до / фиксированного до; английские сольмизационные слоги сохранять и пояснять, особенно ti, не подменять их названиями нот |
| diatonic mode | диатонический лад |
| Ionian / Dorian / Phrygian / Lydian / Mixolydian / Aeolian / Locrian | ионийский / дорийский / фригийский / лидийский / миксолидийский / эолийский / локрийский |
| chromatic scale | хроматическая гамма; сохранить авторские кавычки и объяснение отсутствия чередования тонов/полутонов; отдельного утверждения об отсутствии тоники в снимке главы 14 нет |

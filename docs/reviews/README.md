# Записи проверки глав

Для каждой новой переводимой главы создавайте `<source-id>.md` по [шаблону](../chapter-checklist.md). `source-id` совпадает с ID страницы в `upstream/sources.json`; ID оглавления `toc-*` указывается внутри записи отдельно.

В записи связывайте источник и перевод с точными ревизиями, сохраняйте инвентарь, решения, результаты проходов и следующий шаг. Пути из записи считаются относительно этой папки. Ссылку на запись добавляйте в [трекер](../chapter-tracker.md) и PR.

На момент введения процесса отдельные записи для первых шести черновиков ещё не созданы. Их отсутствие явно отражено в трекере; создавать ретроспективные отметки о невыполненных проверках нельзя. При фактической повторной сверке можно оформить запись текущей датой для проверенных ревизий.
